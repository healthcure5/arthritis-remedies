# Joint Release

The Joint Release website, home of The Joint Reset guide: a landing page, a details page and a thank-you page.

Visitors get the free guide (`guide-files/7-bad-habits-that-keep-joints-stiff.pdf`) by email. To sell The Joint Reset, paste your checkout link into `CHECKOUT_URL` at the top of `site.js`; the buy buttons and the thank-you page offer appear once it is set.

Live at https://gentlerootz.com/
