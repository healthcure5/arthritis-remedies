# Joint Release

The Joint Release website, home of The Joint Reset guide: a landing page, a details page and a thank-you page.

Visitors get the free guide (`7-everyday-habits.pdf`) by email. To sell The Joint Reset, paste your checkout link into `CHECKOUT_URL` at the top of `site.js`; the buy buttons and the thank-you page offer appear once it is set.

Live at https://healthcure5.github.io/arthritis-remedies/

## Test version (gh-pages branch)

This branch is a trial of visual changes and is not the live site. It has larger text, a shorter home page, a two-field signup form, and the course restyled in the site's blue with a link in the menu. The live site is still published from `main`.
